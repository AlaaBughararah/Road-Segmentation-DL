# Dataset Instructions

Dataset:
https://www.kaggle.com/datasets/balraj98/deepglobe-road-extraction-dataset

Add this dataset as an input to the Kaggle notebook.

Satellite images have filenames ending in _sat.jpg.
Their matching road masks end in _mask.png.

Member 2 will add the final training, validation, and test image lists
under data/splits/. All members must use these same lists.

Do not upload the full dataset here.
